# Python for Data Science

A piscine (intensive training) introducing Python for Data Science concepts.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 0 | Python - 0 - Starting | Python basics: data structures, functions, packages |
| 1 | Python - 1 - Array | NumPy arrays and array manipulation |
| 2 | Python - 2 - DataTable | Pandas and data manipulation |
| 3 | Python - 3 - OOP | Object-oriented programming in Python |
| 4 | Python - 4 - Dod | Data science advanced topics |

## Requirements

- Python 3.10 or higher
- Each project must be completed in order before moving to the next

## Rules

- No wildcard imports (`from module import *`)
- No global variables
- From project 5 onwards: all functions must have docstrings, follow `flake8` norm

## Usage

Each project lives in its own directory. Navigate to the project folder and follow the instructions in the subject PDF.
